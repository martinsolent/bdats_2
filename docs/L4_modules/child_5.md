# Introduction to Databases COM430



Databases are at the heart of most of the websites, apps and IT systems that we use on a daily basis, for example online e-commerce websites, online banking, booking systems, social media apps, even online gaming. Furthermore, virtually all businesses use databases to underpin their critical line of business systems like HR, Payroll and CRM.

In this module, students are introduced to the skills and concepts required for querying, designing and implementing relational databases and developing database applications.

As well as providing a solid introduction to relational databases and the SQL language, the module will build on the Python skills studied in the previous semester by learning how to interact with databases in Python.

Students will also learn fundamental skills such as interpreting user requirements, designing, testing and presenting data.

A basic understanding of databases is important for all IT careers and will significantly enhance employability.

What you will learn:


By the end of this module, students will be able to:

* Query a relational database using the SQL language to produce a report according to a specific user need.

* Understand relational databases entities, relationships and integrity.

* Design and implement a new database and extending an existing one.

* Build a database application to meet defined user requirements

* Perform effective testing to ensure that you are producing accurate information, that functional requirements are met and database integrity is maintained.

* Write a structured, concise and referenced report
